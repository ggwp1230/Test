## Как играть / How to play (max 1000)
**RU:**
```
1. Нажмите «Играть» в главном меню
2. Внизу экрана появятся 3 случайные фигуры
3. Нажмите на фигуру, чтобы выбрать её
4. Нажмите на клетку поля, чтобы разместить фигуру
5. Заполните весь ряд или столбец — он очистится автоматически
6. За каждый блок начисляются очки, за очистку линий — бонус
7. Очистите несколько линий одновременно для комбо-бонуса
8. Когда все 3 фигуры использованы — появляются новые
9. Игра заканчивается, когда ни одна фигура не помещается на поле

Совет: планируйте размещение заранее, оставляйте место для крупных фигур!
```

**EN:**
```
1. Press "Play" in the main menu
2. Three random shapes appear at the bottom of the screen
3. Click a shape to select it
4. Click a cell on the grid to place the shape
5. Fill an entire row or column — it clears automatically
6. You earn points for each block placed, plus bonus for clearing lines
7. Clear multiple lines at once for a combo bonus
8. When all 3 shapes are used — new ones appear
9. The game ends when no shape can fit on the board

Tip: plan your placements ahead, leave room for larger shapes!
```
